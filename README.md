## 先把概念理清：住宅 IP、原生 IP、双 ISP 到底差在哪

很多人搜"香港住宅 IP VPS"时，其实并不完全清楚自己要的到底是哪一种 IP。丽萨主机官方页面把这些概念混在几个不同产品线里卖，如果不区分清楚，下单很容易选错。

**机房原生 IP**：IP 归属地在香港，ASN 是数据中心或云厂商，能解锁一部分不严格的港区服务，但在 TVB、Netflix 这种对 IP 类型敏感的平台面前，容易被判定为"机房流量"而触发地区限制或验证码。

**ISP IP**：IP 的 ASN 登记为某家 ISP（互联网服务提供商），看起来比纯机房 IP 更"像"普通用户，但严格来说仍属于商业宽带范畴，解锁能力介于原生和住宅之间。

**住宅 / 家宽 IP（Residential IP）**：IP 真实登记在香港本土家庭宽带运营商名下（比如 HGC、iCable 这类），在流媒体平台眼里和一个香港家庭用户没区别，这是稳定解锁 TVB、Netflix 港区、Cityline 票务的关键。

**双 ISP 住宅 IP**：丽萨主机主推的说法，指的是 IP 同时具备两家 ISP 的属性登记，纯净度更高，被风控系统标记的概率更低，适合做账号养号、社媒营销这类对 IP 质量敏感的任务。

简单说：如果你只是建站或当中转，三网直连 CMI 那条线就够了，延迟低、价格也最低；如果你要解锁港区流媒体或做营销养号，就必须上 HGC 或 iCable 的住宅 IP 系列。
